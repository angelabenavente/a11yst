# a11yst trademark and brand policy

This document describes how to refer to a11yst project identity. It does **not** change the license for source code.

## Code license vs. project branding

The Mozilla Public License 2.0 (MPL-2.0) covers the a11yst Community source code distributed in this repository. It does not grant a general license to use the a11yst project name, logo, or visual identity.

You may use, modify, and distribute the Community code under MPL-2.0. Trademark and branding rules in this document address how the project is identified, not whether the code may be used commercially.

## Permitted referential use

Truthful, non-misleading references are generally acceptable, for example:

- "uses a11yst"
- "compatible with a11yst"
- "based on a11yst"
- "fork of a11yst"

These references must not imply sponsorship, endorsement, or official status from the a11yst project.

## Forks and modified distributions

If you distribute a modified version of a11yst Community, use your own product name and branding when there is a reasonable risk of confusion with the official project.

You may identify the origin factually, for example:

- "Based on a11yst"

Do not present a modified fork as the official a11yst product.

## Not permitted without permission

Do not present a product or service as:

- official a11yst
- an official a11yst offering
- a11yst Pro, Team, Cloud, or Enterprise (or similar names that imply an official commercial product from this project)

when it is not operated or authorized by the a11yst project maintainers.

This policy addresses brand confusion. It does not prohibit creating commercial products that use a11yst Community source code under MPL-2.0.

## Logo and visual identity

The a11yst name, logo, and visual identity are project identity assets.

Do not use those assets in a way that suggests your product is the official a11yst project or is endorsed by it, unless you have explicit permission.

## No registration claims

This document does not claim that a11yst is a registered trademark. Do not describe a11yst as a registered mark unless a maintainer publishes confirmed registration details.
