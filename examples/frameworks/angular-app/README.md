# angular-app

Minimal Angular 18 standalone app with explicit a11yst routes (Angular routing is not parsed).

> **Note:** Angular CLI dev startup is slower than Vite or static HTML examples.

## Expected routes

| Path | Finding |
| --- | --- |
| `/` | None |
| `/contact` | `button-name` (empty `<button>`) |

## Commands

```bash
pnpm dev
PORT=4600 pnpm dev
```
