# html-basic example

Minimal static HTML site with two routes for a11yst Phase 1 planning.

## Routes

- `/` — home page
- `/about` — about page

## Serve locally

```bash
pnpm start
```

Serves on `http://localhost:4173` (override with `PORT`).

## a11yst config

See `a11yst.config.ts`. Planning only in Phase 1 — no browser audit yet.
