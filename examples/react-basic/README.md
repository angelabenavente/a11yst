# react-basic example

Minimal React + Vite app with two routes for a11yst Phase 1 planning.

## Routes

- `/` — home
- `/settings` — settings

## Develop

```bash
pnpm dev
```

## a11yst config

`a11yst.config.ts` schedules:

- 2 routes
- profiles: `default`, `keyboard`
- viewports: mobile + desktop

Expected planned runs: `2 × 2 × 2 = 8`.
